HOW TO MODIFY THE DATA:
========================================

1. Edit the EXPERIMENTAL_DATA dictionary in create_violin_plots_paper.py
2. For standard methods: Modify 'coverage', 'coverage_std', 'mpiw', 'mpiw_std'
3. For learnable method: Modify overall values AND size-specific values
4. Rerun the script to generate updated plots

Example modification:
EXPERIMENTAL_DATA['coco']['learnable']['small']['mpiw'] = 12.0  # Change small object MPIW
EXPERIMENTAL_DATA['coco']['learnable']['small']['mpiw_std'] = 1.5  # Change variance

Random seed used: 42 (for reproducibility)
Standard methods: 100 samples (representing calibration trials)
Learnable method: 50 samples (representing training epochs)
